## ⚡ The Process: From Noise to Clarity

NiveshIQ operates on a high-velocity 4-phase ingestion pipeline:

1. **Phase One: Ingestion**
   - Securely ingest Consolidated Account Statements (CAS) via PDF or Excel.
   - Zero-knowledge protocols ensure data privacy and integrity.

2. **Phase Two: Performance**
   - Forget simple returns. We compute **Time-Weighted Internal Rates of Return (XIRR)** across all assets.
   - Real-time market data integration via NSE/yfinance APIs.

3. **Phase Three: Exposure**
   - Identify hidden risks. We cross-reference the top 100 holdings of every fund to reveal **Fund Overlap**.
   - Visualization of "Hidden Beta" and sector-specific over-exposure.

4. **Phase Four: Intelligence**
   - Receive a prioritized list of **Tactical Rebalancing** maneuvers.
   - AI-driven insights optimized for tax efficiency and long-term geometric growth.

## 🏗️ Architecture Stack

### Core Technologies
- **Frontend**: Next.js 14, Tailwind CSS, Framer Motion, Lenis Scroll.
- **Backend**: FastAPI (Python 3.11), Pydantic, JWT Auth.
- **AI Core**: Anthropic Claude 3.5 Sonnet (Advanced Reasoning & Action Planning).
- **Data Engine**: Pandas, PyXIRR (Mathematical Precision), yfinance, NSE API.
- **Persistence**: MongoDB (User Data), Redis (NAV Cache).

## 🚀 Deployment & Local Setup

### System Requirements
- Node.js 18+ & Python 3.11+
- MongoDB & Redis Instance
- Anthropic API Key (Claude 3.5)

### Initializing the Node
```bash
# Clone the repository
git clone https://github.com/yourusername/niveshiq.git
cd niveshiq

# Frontend Installation
cd apps/web
npm install
npm run dev

# Backend Installation
cd ../api
pip install -r requirements.txt
uvicorn main:app --reload
```
